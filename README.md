# React Personal Notes Fundamental

Repository ini berisi project **Belajar Fundamental Aplikasi Web dengan React**.

Project merupakan aplikasi catatan pribadi berbasis React dengan halaman catatan aktif, arsip, detail catatan, penambahan catatan, pencarian, dan routing.

## Fitur

- Menampilkan catatan aktif
- Menampilkan catatan arsip
- Menambahkan catatan baru
- Menghapus catatan
- Mengarsipkan dan memindahkan catatan kembali
- Melihat detail catatan
- Pencarian catatan
- Routing antarhalaman
- Halaman 404

## Menjalankan project

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Teknologi

- React
- React Router
- Vite
- JavaScript
- CSS
